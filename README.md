10+ years building high-performance apps for **fintechs and healthtechs**, across mobile, frontend and backend. I care about systems that stay up, load fast and are still readable six months later.

Open to **contracts and projects** through Accalia.

## What I do

- **Mobile end to end**: React Native (iOS/Android), New Architecture, offline-first, push, biometrics
- **Architecture** that scales: BFF, GraphQL, micro-frontends, microservices, feature-based structure
- **Frontend performance**: Core Web Vitals, rendering, bundle size
- **Design Systems** teams actually reuse
- **End-to-end SaaS**: from schema to app store
- **LLM integrations** in production, not demos (RAG included)
- **Mentoring**, code review and technical decision-making

## Where I've shipped

- **Creditas**: React Native app with 5M+ downloads, Server-Driven UI, BFFs in Express and GraphQL
- **Healo** (Stockholm): event-driven microservice consuming Kafka, remote full-time
- **Crédito Social**: migrated the app to the React Native New Architecture, BFF in Fastify
- **Unimed**: telemedicine feature in the member app
- **Corsan**: offline-first field service app, built from scratch
- **HotFloor / SmartLy**: IoT app to control heating and room climate
